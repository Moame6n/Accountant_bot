# بوت الأدوات المحاسبية 🧮

## الملفات
- `bot.py` — الملف الرئيسي
- `tools.py` — الأدوات المحاسبية
- `config.py` — الإعدادات
- `requirements.txt` — المكتبات

## خطوات التشغيل

### 1. افتح config.py وعدّل هذه البيانات:
```python
TOKEN = "توكن البوت من BotFather"
CHANNEL_ID = "@اسم_قناتك"
AFFILIATE_LINK = "رابط الأفلييت"
```

### 2. شغّل البوت:
```bash
python bot.py
```

## الأدوات المتاحة
- ضريبة القيمة المضافة 14%
- حاسبة الاستهلاك (القسط الثابت)
- حاسبة مجمل الربح
- حاسبة نقطة التعادل

## نظام Forced Subscribe
البوت لن يعمل مع أي مستخدم قبل الاشتراك في قناتك.
